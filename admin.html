Sikkerhet og personvern

Hvem kan se hva? 🛡️

Med familiekoden: Leser bare det historiske slektstreet over avdøde personer. Ingen administrasjon.

Med egen godkjent innlogging: Kan bruke familierommet og legge inn historier og bilder til det delte historiske arkivet.

Med administratorkontoen: Du får tilgang til dette panelet og kan endre familiepassord, medlemsstatus og historiske slektsdata.

Levende personer: Private profiler og ditt familieutkast er fortsatt knyttet til din personlige konto. Det er ikke laget et felles publiseringssamtykke for levende slektninger ennå.

Sider på GitHub kan fortsatt ha gamle historiske data i tidligere versjoner. Endringene her fjerner ikke historiske kopier i Git-repositoryet.
